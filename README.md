# CSE317 - Computer Networks and Security

## 📂 Repository Structure
The repository is organized by lab sessions. Each folder contains the Packet Tracer file (`.pkt`), a topology screenshot, and the CLI commands used for configuration.

##  How to Run the Projects
1. Clone this repository: `git clone https://github.com/golammonayem/CSE317-Computer-Networks-and-Security.git`
2. Open the `.pkt` files using **Cisco Packet Tracer**.
3. Check the command files for step-by-step CLI instructions.
